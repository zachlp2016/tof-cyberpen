# Projects

Active work, one folder per work item. New work starts here, in its own folder: `projects/<kebab-case-name>/`.

Each project folder contains a `README.md` with the goal, status (active | done | paused), and links to related wiki pages. Durable knowledge learned during a project is promoted to the wiki (sources / concepts / entities / analyses); project folders hold working material, and the wiki holds knowledge.

Full rules: [AGENTS.md](../AGENTS.md) → "Work folder conventions". Wiki catalog: [wiki/index.md](../wiki/index.md).
