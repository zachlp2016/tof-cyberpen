## How agents use it

    perform a penetration test on:
    ip address: 192.168.10.500
    port: 8000
    type: basic | normal | extensive | hack

- **MCP (preferred)**: server node tof-pentest/bin/tof-pentest.js mcp → tool pentest {ip, port, type}; also plan, run_tool, list_tools, get_report
- **CLI**: node tof-pentest/bin/tof-pentest.js scan --ip 192.168.10.500 --port 8000 --type normal
- **Docker**: docker run --rm tof-ai-pentester scan --ip … --port … --type … (or docker/run.sh …, which mounts runs/ so reports land on the host)
- **Agent docs**: top-down entry at [projects/penetration/agents.md](../projects/penetration/agents.md) → per-tool shell commands in [tool_usage/](../tool_usage/nmap.md), vendored apps in [tools/](../tools/ffuf/README.md), tier plan data in [manifest.json](../tof-pentest/src/manifest.json)

## Build platform note

The image was built for **linux/arm64** (native for this Mac). For amd64 Linux boxes, rebuild with:

    docker buildx build --platform linux/amd64 -f docker/Dockerfile -t tof-ai-pentester .

The installers are already platform-aware, so no changes are needed.
